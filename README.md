**Q：CN2 GIA 和普通 CN2 有什么区别？**
CN2 GIA（AS4809）是电信最高级别回国线路，全程走高速通道，晚高峰丢包率低；CN2 GT 是混合线路，国际段走 CN2，国内段可能切到 163 骨干，高峰期可能拥堵。恒创日本节点走的是 CN2 GIA。

**Q：续费真的同价吗？**
是。保持和首次购买相同的续费周期（比如年付续年付），价格不变。改周期会回到原价。

**Q：日本节点能解锁 Netflix 日区吗？**

**Q：支持哪些支付方式？**
